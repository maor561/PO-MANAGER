# 📦 מערכת מעקב רכש (PO Tracking System)

מערכת מעקב רכש משולבת למעקב שרשרת אספקה מדרישת רכש ועד קליטה במחסן.

## 🎯 תכונות ראשיות

### 📊 דאשבורד חזותי
- **סה"כ הזמנות** - סך כל ההזמנות במערכת
- **הזמנות שהושלמו** - הזמנות שהגיעו לשלב הקליטה הסופית
- **הזמנות מתעכבים** - הזמנות שעברו את תאריך המועד עדיין בתהליך
- **סה"כ הוצאות** - חישוב כלכלי של כל ההזמנות

### ➕ ניהול הזמנות
- **הוסף הזמנה** - יצירת הזמנה חדשה עם פרטים מלאים
- **עדכן הזמנה** - שינוי פרטי הזמנה קיימת
- **מחק הזמנה** - הסרת הזמנה מהמערכת
- **התקדמות בשלבים** - עדכון שלב ההזמנה

### 📋 שלבי שרשרת האספקה

1. **דרישת רכש** 🔵 - שלב התחלתי
2. **אישור הנהלה** 🟣 - אישור פנימי
3. **הנפקת הזמנה** 🟠 - שליחה לספק
4. **שליחה מהספק** 🟢 - הזמנה אצל הספק
5. **קבלה במחסן** 🔷 - קבלה בחנויה/מחסן
6. **קליטה סופית** ✓ - קליטה וסיום

### 💾 יצוא ויבוא
- **יצוא ל-Excel** - שמירת כל הנתונים לקובץ Excel
- **יבוא מ-Excel** - טעינת הזמנות מקובץ Excel קיים

## 🚀 התחלה מהירה

### דרישות מערכת
- דפדפן עדכני (Chrome, Firefox, Edge, Safari)
- לא נדרש שרת או התקנה

### הפתחת היישום
1. פתח את הקובץ `index.html` בדפדפן
2. המערכת תטען אוטומטית

### הוספת הזמנה ראשונה
1. לחץ על כרטיסייה **"הוסף הזמנה"**
2. מלא את הפרטים:
   - **מספר הזמנה**: למשל PO-001
   - **תאריך**: תאריך יצירת ההזמנה
   - **ספק**: שם הספק
   - **פריט**: שם המוצר/שירות
   - **כמות**: מספר הפריטים
   - **מחיר יחידה**: מחיר למוצר בודד
   - **מועד אספקה**: תאריך יעד לקבלה
3. לחץ **"הוסף הזמנה"**

### עדכון התקדמות
1. לך לכרטיסייה **"הזמנות"**
2. בחר שלב חדש מה-dropdown או לחץ חץ (→) להתקדמות אוטומטית
3. העדכון מתבצע מיד

### צפייה בסטטיסטיקות
- לך לכרטיסייה **"דאשבורד"** לצפייה בתמונה כוללת

## 💾 שמירת נתונים

הנתונים נשמרים אוטומטית ב-**localStorage** של הדפדפן:
- שמירה מיידית לאחר כל שינוי
- הנתונים נשמרים גם אחרי סגירת הדפדפן
- אפשר לנקות נתונים דרך כפתור **"מחק הכל"**

## 📥📤 עבודה עם Excel

### יצוא לקובץ Excel
1. בדאשבורד, לחץ **"📥 יצוא ל-Excel"**
2. קובץ Excel יוקם עם כל הנתונים
3. שם הקובץ: `הזמנות_[תאריך].xlsx`

### יבוא מ-Excel
1. בדאשבורד, לחץ **"📤 יבוא מ-Excel"**
2. בחר קובץ Excel (xlsx, xls, csv)
3. ודא שהעמודות בקובץ תואמות למבנה:
   - מס הזמנה
   - תאריך
   - מועד אספקה
   - ספק
   - פריט
   - כמות
   - מחיר יחידה
   - שלב (אופציונלי, ברירת מחדל: 1)
   - הערות (אופציונלי)

## 🎨 ממשק המשתמש

### כפתורים בטבלה
- **✏️** - עדכן הזמנה
- **🗑️** - מחק הזמנה
- **→** - התקדמות לשלב הבא

### אינדיקטורים צבעוניים
- **צהוב** בשורה = הזמנה מתעכבת
- **ירוק** = הזמנה הושלמה (שלב 6)

### שינוי עיצוב

## 🐛 טיפול בבעיות

### הנתונים לא נשמרים
- ודא שלוקל סטורג' מופעל בדפדפן
- נסה דפדפן שונה
- בדוק את ה-console (F12) לאם יש שגיאות

### בעיות בייצוא ל-Excel
- וודא שאתה משתמש בדפדפן תומך (Chrome, Firefox, Edge)
- נסה לרענן את העמוד (F5)

## 📞 תמיכה

לשאלות או בעיות:
1. בדוק את console הדפדפן (F12)
2. נסה לנקות את ה-cache (Ctrl+Shift+Delete)
3. הסר את הנתונים והתחל מחדש בכפתור "מחק הכל"
